# AI Language Translation Tool

A web-based language translation application developed using Python, Flask, HTML, CSS, JavaScript, and the `deep-translator` library. 

## Features
- Translates between multiple global and regional languages.
- Google Input Tools transliteration support for Romanized Indian language input.
- Responsive dark-mode user interface with swap, clear, and one-click copy options.
